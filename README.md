# Neovim Go IDE Config

My personal Neovim configuration for Go development.

## Features

- 🚀 Full Go development support (gopls, go.nvim)
- 🔍 Fuzzy finder (Telescope)
- 🐛 Debugger (DAP + Delve)
- 📁 File explorer (Neo-tree)
- ✨ Autocompletion (nvim-cmp)
- 🎨 TokyoNight theme

## Keybindings

| Key | Action |
|-----|--------|
| `Space + ff` | Find files |
| `Space + fg` | Live grep |
| `Space + e` | File explorer |
| `gd` | Go to definition |
| `K` | Hover info |
| `Space + gr` | Go Run |
| `F5` | Debug start |
| `F9` | Toggle breakpoint |
EOF
